## 宗旨

本库的宗旨只有一个：

> **根除千年奴性，实现由民作主的社会主义公有制。**

所做的一切——文章的收集、整理、校对、公开、传播——**无偿为人类的每一个人民群众服务**。

不为流量，不为名声，不为交易。只为让人民群众睁开眼睛，看清自己的处境，把被颠倒的是非重新颠倒过来。
